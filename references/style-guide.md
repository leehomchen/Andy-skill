# 文案风格指南

按视频风格基调选择措辞、句式和节奏。

## 燃向 / 激情（宣传片、运动、科技）

- 短句、动词开头、强节奏
- 用词：突破、极致、瞬间、点燃、超越、巅峰、势不可挡
- 句式：四字短语 + 排比。"踏光而来，破势而出，一往无前。"
- 配音：浑厚男声（YunjianNeural），语速 +5%~+10%
- 音乐：大气鼓点 + 弦乐渐强 + 电子低频

## 温情 / 治愈（生活、情感、亲子）

- 长句渐缓，画面感强
- 用词：温暖、陪伴、时光、记得、那些、慢慢
- 句式："有些事，不用太急。慢慢来，比较快。"
- 配音：温柔女声（XiaoxiaoNeural），语速 -5%~+0%
- 音乐：钢琴、木吉他、轻弦乐

## 科技 / 专业（产品、SaaS、B2B）

- 理性、数据驱动、逻辑清晰
- 用词：效率、提升、成本、智能、一体化、解决方案
- 句式："一个系统，搞定三件事。"
- 配音：清晰男声（YunxiNeural），语速 +10%
- 音乐：克制电子节拍、脉冲音效

## 搞笑 / 接地气（短视频、种草、生活）

- 口语、网络热词、反差梗
- 用词：绝了、离谱、谁懂啊、直接封神、家人们
- 句式："谁懂啊，这玩意儿居然……"
- 配音：东北口音（liaoning-XiaobeiNeural）或活泼女声，语速 +15%
- 音乐：轻快、俏皮、音效密集

## 通用法则

1. **开头3秒定生死**：钩子必须强——提问、反常识、利益直给、冲突画面
2. **说人话**：删掉"赋能、抓手、闭环"这类黑话（除非面向B端专业受众）
3. **数字具体**：不说"很快"，说"3秒"；不说"很多"，说"10万人在用"
4. **结尾有动作**：明确告诉观众下一步——点赞、评论、关注、下单
5. **一镜一意**：一个镜头只讲一件事，信息密度适中
